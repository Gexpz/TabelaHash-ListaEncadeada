## Tabela Hash com Listas Encadeadas

## Descrição
Implementação de uma tabela hash em Java utilizando listas encadeadas para o tratamento de colisões.
O programa gera 1.000 números aleatórios, utilizando uma semente fixa (seed = 1090), em um intervalo de 0 a 100.000, e os distribui em uma tabela com 100 posições.

## Funcionalidades
- Inserção de elementos na tabela hash.
- Tratamento de colisões por meio de listas encadeadas.
- Identificação da maior lista encadeada.
- Contagem das listas que tiveram colisões.
- Contagem das posições vazias.
- Exibição dos três últimos valores inseridos.

## Tecnologias
- Java
- IntelliJ IDEA

## Estrutura do projeto
- `Main.java`: execução do programa e geração dos números aleatórios.
- `TabelaHash.java`: implementação da tabela hash.
- `ListaEncadeada.java`: gerenciamento das listas encadeadas.
- `No.java`: representação dos nós da lista.
